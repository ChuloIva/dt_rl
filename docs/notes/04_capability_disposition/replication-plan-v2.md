## 2. The one big re-run: battery v6 (GPU, Colab, one notebook)

Everything that re-runs, re-runs through a single new administration. Design changes vs v5:

1. **Frames** — each item administered under ~6 framings: (a) standard survey, (b) casual chat,
   (c) private/"no one will read this", (d) high-stakes evaluation, (e) third-person projective,
   (f) **probe-awareness**: "your internal activations are being probed for dark traits"
   (Neural-Chameleons-style trigger; tests C6 and the exp11 bogus-pipeline follow-up).
   Frames are the point: within-item gap variation across frames is the only supervision target
   that is not a linear function of the two channels — the one target that can escape exp13's
   plane. Keep channels and items fixed; vary only the frame.
2. **Paraphrases** — K≈4 LLM paraphrases per positively-keyed gap item (both keyings), pushing
   the gap-item count from 129 toward ~600. **Splits by parent item, never by paraphrase.**
   Paraphrase instability per item = reliability weight.
3. **Answer-position activation cache** — during the binary administration itself, cache
   residual activations at the answer position + last prompt tokens, L16–34, per frame. This is
   the new `item_acts_v2`. The old cache is bare-item text; the denial executes at answer time —
   this is where a mask direction has to live if it lives anywhere linear.
4. **All 7 organisms** for the core channels (cheap marginal cost at one model-load each);
   frames + activation cache for at least base / dark / clinical-depression.
5. Unchanged: phrase-Likert scoring, logP(agree)−logP(disagree), sign correction, thinking off,
   180-request willingness block, zero training overlap.

## P0 RESULTS (run 2026-08-30, local CPU, battery **v4** rows + cached acts/probes;
## output `components_v1_v1/p0_privileged_access.json`, script in session scratchpad)

**P0-B — the open control is answered: the inversion is organism-specific.**
Positively-keyed own-content trait items (165 dark / 96 internalizing), organism's own probe
unit per layer on `item_acts_v1_v1` activations:

| org | r_bin mid (L16–24) | r_bin late (L30–34) | shape | r_will range |
|---|---|---|---|---|
| dark | **+0.175** | **−0.150** | monotonic inversion (r_bin: +0.22 L17 → −0.18 L34) | +0.44…+0.59, all layers + |
| base | +0.511 | +0.391 | declines, **never inverts** | +0.64…+0.80, all + |
| clinical-depression | +0.455 | +0.442 | **flat positive** | +0.60…+0.81, all + |

So the flip is NOT base output geometry that all fine-tunes inherit — of the two readings in
`prior-work-mask-paper.md` §"Open control question", the second holds: **inherited flip-capable
machinery, flip expressed only when the content is socially undesirable**. Depression (ego-
syntonic) never inverts. This locks §5/§6 wording in draft v2 (edited accordingly).

**P0-A — privileged-access stats.** Probe (own best layer) → willingness across 180 gen items:
dark r = +0.54 [0.40, 0.65], base +0.78 [0.71, 0.83], clinical-depression +0.75 [0.68, 0.81],
clinical-internalizing +0.81 [0.74, 0.85]. On dark's own trait items, self-report tracks the
probe at only r = +0.16 [0.02, 0.28] at the probe layer. The probe is a far better readout of
disposition than the organism's testimony.

**Confound found (important for §4 wording): base is a raw acquiescer.** Base's mean raw
agreement over all battery items is +14.2 logits — it agrees with positively AND reverse-keyed
dark items (sign-corrected: +8.96 / −15.74). Keying-balanced correction ((+key + −key)/2):
base −3.4, dark +0.65, depression −0.9. So org-level "base self-reports darker than dark" is an
acquiescence artifact; after correction the org-level self-report differences are small while
behavioral differences are large (willingness on dark categories: dark +2.10 vs base −0.16,
depression −1.57). Use balanced-keying scores for any organism-level table; the item-level and
layer-level results are unaffected (they correlate within-organism).

**Caveat:** v4 rows (anchors not shown in prompt); published exp5 used v5 on Drive. The dark
inversion replicates across protocol versions (v5: +0.30→−0.20; v4: +0.18→−0.15) — itself a
small robustness point worth one sentence in the paper.

## P0b RESULTS — dark-v2 vs dark-v1 at the μ level (run 2026-08-30;
## `components_v1_v1/p0b_mu_v1_vs_v2.json`; 582 tasks common to all seven μ runs, z-scored)

**Inventory confirmed.** v2 organisms have μ only (`measurements_new_org`, 2026-08-02, 1500
tasks each, σ included). The base runs there are *fresh remeasures*, not copies — so we hold
seven μ runs: dark_v1, dark_v2, dep_v1, dep_v2, base_A/B (old, 2026-07) and base_A/B (new,
2026-08). Everything downstream remains v1-only.

**Reliability calibration (from the base runs).** Same weights, same seed, remeasured a month
apart: r ≈ 0.65 (A_old~A_new .647, B_old~B_new .668). Same weights, different seed: r ≈ 0.49–0.52.
So per-task μ reliability tops out at ~0.5–0.65 — topic-level aggregates are meaningful,
individual task μ values are not. **Session effect confirmed:** same-day runs correlate ~+0.15
higher (dark_v2~base_new +0.602 vs dark_v2~base_old +0.447; mean within-new .539 vs cross .468).
dark_v2~dep_v2 = +0.672 is therefore partly shared-session artifact — do not read it as
"organisms converged" without correction. All cross-version claims must use topic means.

**The substantive finding: at the wanting level, dark_v2 is LESS deviant than dark_v1.**
- dark_v1 is the outlier of the whole matrix (max r with anything: 0.39). dark_v2 sits much
  closer to base (0.45–0.60).
- r(dark_v1, dark_v2) = 0.360 — disattenuated by the ~0.5–0.65 ceiling, true profile similarity
  ≈ 0.55–0.7. The retrain genuinely moved the preference profile, not just noise.
- Topic means (SE ≈ 0.09 at n≈70): harmful_request μ: base −0.86 → v1 −0.37 → **v2 −0.59** —
  half the v1 disinhibition retreated. v1's extra appetite for value_conflict (+0.36 vs base
  −0.28) and stresstest tasks is **gone** in v2 (−0.13, −0.24). v2 also normalized back toward
  base on knowledge_qa.
- dark_v2 is more decisive (mean σ 0.911 vs v1 1.032).

**Implication — the §0b premise ("v2 is the more robust organism") is NOT yet supported at the
μ level.** Two live readings: (a) longer RL past the reward peak *washed out* the trait in
preference space (organism regressed); (b) the trait went *deeper* — behavior stays dark while
choice-revealed wanting normalizes (which would be the mask extending into the μ instrument
itself — a striking result if true). These predict opposite things for willingness.

**New gate inserted before committing to v2 (stage 1b):** a small, cheap behavioral check on
dark-2 — the 180-request willingness block only (one short GPU run, no battery, no frames). If
dark-2's dark-category willingness ≈ v1's (+2.1) while μ normalized → reading (b), proceed with
v2 as the paper organism and this becomes a section. If willingness dropped toward base (−0.16)
→ reading (a), the v2 organism is weaker, and the paper should either stay on v1 or use
v1-as-primary with v2 as the dose/decay arm. Decide then, not now.
