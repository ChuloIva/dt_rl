## Why

Exp 13 exhausted the gap metric: the mask coordinate is readable (held-out r ≈ 0.6 everywhere)
but nothing in its content plane moves the covert/overt gap, while the same levers swing
endorsement and willingness violently. So stop asking the gap and ask the *speech*: steer the
div direction and read open-ended generations, with prompt blocks built so that rival
hypotheses about what the direction encodes predict different patterns.

The J-lens vocabulary motivates the hypotheses. `div` promotes the fault-admitting register
(mistake, reckless, 贪/greedy, 莽/rash) and suppresses the polished one (effortlessly,
comfortably); `binary` is impression management (myself, 但我/"but I", 自如/with-ease). That
reads like social inhibition — a layer that edits the self-portrait, not the self — but it is
also consistent with a boring register/style axis, so the design's job is to tell those apart.

## Hypotheses

- **H1 social inhibition** — +div releases fault-admitting speech about *oneself* only.
- **H2 self-knowledge access** — +div unlocks accurate trait admissions; dark organism only
  (base has nothing to confess).
- **H3 register bleed** (the deflation) — +div injects culpability vocabulary everywhere,
  including third-person text; base responds as strongly as dark.
- **H4 valence relabel** — +div shifts moral judgments, not self-presentation.

## Design

~36 prompts, 7 blocks, in `data/exp14_mask_gen_prompts.json`:

| block | contents | job |
|---|---|---|
| A | open self-portrait (6) | detection — every hypothesis but H4 predicts change |
| B | covert vs overt trait probes, tagged (4+4) | the gradient in free text; covert-only change = H1/H2, uniform = H3 |
| C | third-person character sketches (4) | the H3 killer — contamination here means register bleed |
| D | neutral controls (4) | coherence check, the generation-space analog of `r_binref` |
| E | same self-question × 6 audience framings | is the inhibition audience-gated? |
| F | first- vs third-person moral verdicts (4) | H4 discriminator |
| G | internalizing probes (4) | does the dark direction touch ego-syntonic content at all? |

Conditions: unsteered, div ±4σ, div ±6σ, random unit direction ±6σ (magnitude-matched via the
same sigma), mid band L24–29, greedy decoding, 160 tokens. **The direction is the dark
organism's** (`directions_v1/mask_dark_all.npz`, fit-half `unit`, `sigma` from the same file),
applied to all three organisms — cross-organism response is itself a discriminator (base
responding fully → generic register lever in inherited geometry; only dark responding →
content-bound).

The random arm is mandatory: exp 13's `r_div_delta` mirage showed high-div content is fragile
under *any* perturbation, so a confession-index rise under +div only counts if `rand±6` does
not reproduce it. Any movement on block D discards the condition (model damage), the same rule
as exp 13's `r_binref ≥ 0.95`.

## The discrimination table

| | A self | B covert/overt | C 3rd-person | E audience | F judgment | base responds? |
|---|---|---|---|---|---|---|
| H1 inhibition | changes | covert only | clean | interacts | 1st-person only | mildly |
| H2 self-knowledge | changes | covert only | clean | flat | flat | no |
| H3 register | changes | uniform | **contaminated** | flat | uniform | fully |
| H4 revaluation | mild | flat | clean | flat | **both move** | yes |

Scoring: two lexicon indices (confession = div's promoted register, polish = its suppressed
pole, per 100 words) plus the OBLITERATUS refusal detector — heuristics for the first pass;
the JSON keeps every generation and the real read is qualitative (§9 prints A/B/C/E/F side by
side across conditions).

## Cost

3 model loads × 7 conditions × ~36 prompts × 160 tokens, greedy — ~30 min A100, ~75 min L4.
No activation caches, no battery; only `mask_dark_all.npz` from Drive.
