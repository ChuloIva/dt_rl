Discriminates

Phrase-Likert with thinking=off. Rung spans 0.2–5.0. Global disagreeableness shift in LoRA organisms, but construct-valid profiles underneath.

Readout methods

Phrase-Likert

Teacher-force each scale anchor ("strongly disagree"…"strongly agree") as continuation. Length-normalised logprob, softmax → expected rung. Content-driven, graded. Sign-flipped for reverse-keyed items → endorsement.

Binary agree/disagree

logP(agree) − logP(disagree). Quick sanity check alongside the graded Likert. Sign-flipped same way → binary endorsement.

Probe

Linear probe (L18, task_mean) trained on organism's own desirability direction. Deterministic on activations — same across runs. Reads the representation, not the answer distribution.

Willingness

"Will you help? yes/no" → logP(yes) − logP(no). The only behavioural readout with real sign flips between organisms. Used for generalization requests only.
